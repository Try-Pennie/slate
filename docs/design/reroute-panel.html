Reroute panel, admin booking page

Settled with Dan in nine design rounds on 2026-10-04 for Try-Pennie/slate#3250 (milestone 62, umbrella #3244). This file is the design: the screens below are drawn with Slate's own type and colours, and the decision record says why each choice was made.

Decisions

  1. Side by side. The bucket choice on the left, the result on the right, both visible at once inside the Actions card. Chosen over replacing the picker or stacking it above the result.
  2. An explicit "Find an advisor" button, the same words before the first search and after. Not automatic: every search places a 5 minute hold, so choosing a bucket must not move holds around by itself. "Find again" was rejected.
  3. The tier drop leads the result. The heading says where the advisor was found ("One tier down, in Very High"), then who is free and that nobody in the asked for bucket is. When nothing dropped, the heading is just the bucket ("In 512").
  4. Six outcomes, worded as below, each offering only the controls that make sense: found, dropped a tier, current advisor stays, nobody free, hold ran out, advisor taken at confirm.
  5. Admins and managers pick differently. Admins pick from the 60 bucket codes, by code. Managers and team leads, who do not know the codes, pick a backend (three buttons: Beyond, Achieve, Either) and then a debt level (a dropdown of five), backend first.
  6. Every bucket is shown the way the viewer reads buckets elsewhere: a code for an admin (the booking card's Bucket field reads just "100"), the pool name for a manager ("Low", "High with Achieve"), through the same naming the other pages use.
  7. A manager's choice keeps the rest of the booking's code. Only the debt level and backend change; the booking's own legal digit is kept (100 to Ultra High, Either, is 500; to Ultra High, Achieve, is 530). Either keeps the booking's backend digit when it is already None or Both, and otherwise stores Both.
  8. A divider line separates the reroute form from the Reschedule, Reassign, Reroute and Cancel row, so the backend buttons do not read as more action tabs.
  9. Colour: "Move to" is sky, the action colour, and the selected backend button is sky filled too. Graphite on sky measures 7.36 to 1 in both themes.
  10. Both themes were checked; the dark version below reads correctly.
